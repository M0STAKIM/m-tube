Privacy Policy

Last updated: November 2026 · Operated by MOSTAKIM LAB'S

1. What we process

To provide the service we process the links and search terms you submit and the format you choose. These are sent to the configured third-party media providers so they can return results. Search terms may be kept in a local search-history file on the server.

2. Technical data

For security and abuse prevention we use your IP address for rate limiting and keep short-lived technical logs. We keep minimal records in local JSON files on the server: download records (provider, media type, title, status and a hashed IP address), search history (search text, result count and a hashed IP address) and anonymous usage counters.

3. Cookies

M-TUBE sets one session cookie that protects requests against forgery (CSRF). It is not used for advertising or tracking.

4. Third-party providers

Media providers receive the link or query you submit. Their handling of data is governed by their own privacy policies. Provider API keys are kept on the server and are never sent to your browser.

5. Retention

Resolved download references and caches expire automatically within minutes. Downloaded media is delivered to you and any temporary file is deleted right after; records are capped and old entries are removed automatically.

6. Your choices

You can stop using the service at any time. To ask about data we hold, contact us through the Support page.

7. Security

We apply reasonable technical safeguards, but no online service can be guaranteed to be completely secure.

8. Changes

We may update this policy from time to time. The latest version is always available on this page.
